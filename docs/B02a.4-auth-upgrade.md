# Auth.js patch и настоящий Credentials regression

Web использует exact `next-auth@5.0.0-beta.32`, который разрешает `@auth/core@0.41.3`. Direct core override отсутствует. Next в обоих consumers остаётся `15.5.24`, React/DOM resolved `19.2.7`. Auth closure меняет jose `5.10.0 → 6.2.12`, preact `10.11.3 → 10.24.3`, preact-render-to-string `5.2.3 → 6.5.11`; oauth4webapi уже был `3.8.6` и остаётся таким. Старые cookie/@types/cookie/pretty-format удалены из неиспользуемой Auth closure.

Архитектура Credentials-only, edge-safe config и Node authorize сохранена. Generation выдаётся только успешным Credentials sign-in; client update не управляет claims. Legacy/stale/invalid generation и известные seed identities остаются anonymous. DB guard сверяет актуальные status/role/profile/email перед защищённым действием; session endpoint не заменяет такую проверку. SQL/schema/seed и продуктовые права не изменены.

Новые HTTP тесты используют отдельную seed-free синтетическую БД, настоящий Argon2 и серверные auth endpoints. Они проверяют вход ADMIN/REALTOR, неверный пароль/unknown/PENDING/BLOCKED/seed identities, отдельные DB drift, spoofed session update, JWT rejection и полную очистку cookie chunks. Положительный парольный вход не подменяется mint JWT. Инструкции и ограничения fixtures: [e2e/README.md](../e2e/README.md).

Проверки: frozen install (`--ignore-scripts` локально), explicit `pnpm db:generate`, Prisma validate, lint, typecheck, unit tests, build, отдельные DB integration и production E2E. Patch-floor metadata проверка является проверкой графа, а не доказательством эксплуатации advisory. Email/OAuth/getToken exploit testing не выполняется: это не используемые приложением пути.

Этот пакет не запускает live окружения, не изменяет реальные аккаунты и secrets, не выполняет merge/deploy. CI E2E launcher остаётся dev; production regression выполняется отдельно через `next start` на loopback. При локальной проверке app/test origin должен быть единым `localhost`, поскольку Next нормализует loopback IP в redirect URL; bind сервера остаётся `127.0.0.1`.
