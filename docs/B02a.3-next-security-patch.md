# B02a.3 — точечное обновление Next 15.5.24

В корневом package.json и apps/web/package.json Next закреплён точной версией `15.5.24` вместо диапазона `^15.1.6`, который разрешался в `15.5.20`. Оба реальных consumer проверяются через `createRequire`: root и web должны загружать именно 15.5.24.

## Основание

[Advisory GHSA-m99w-x7hq-7vfj от 21 июля 2026](https://github.com/vercel/next.js/security/advisories/GHSA-m99w-x7hq-7vfj) описывает CPU DoS для App Router с Server Actions и исправление в 15.5.21. Исходная 15.5.20 входит в затронутый диапазон. [Security release от 25 августа 2026](https://nextjs.org/blog/august-2026-security-release) рекомендует 15.5.24 для линии 15.5 и отключает обработку AVIF при оптимизации до исправления upstream. Источники проверены 12 сентября 2026.

Доступ атакующего к пути image optimization в этом приложении не доказан; подтверждённая эксплуатация RCE не заявляется. Версионная проверка подтверждает установленный патч, а не воспроизводит DoS. Эксплойты и нагрузочные запросы не запускались.

## Границы зависимостей

Lockfile изменяет только Next, `@next/env` и восемь платформенных пакетов `@next/swc-*` с 15.5.20 на 15.5.24, их integrity и ссылки потребителей. Это точные зависимости manifest Next 15.5.24. Snapshot next-auth получает новую подпись peer Next; версия next-auth остаётся `5.0.0-beta.25`, `@auth/core` — `0.37.2`. React и ReactDOM остаются `19.2.7`, Prisma — `6.19.3`; остальные версии и снимки не меняются. Старый Next отсутствует в используемом lock graph.

## Проверка

Метаданные обоих consumer сначала дают RED на 15.5.20, после lock-only resolution и frozen install с `--ignore-scripts` — GREEN на 15.5.24. Prisma генерируется отдельно. Существующие `pnpm test`, `pnpm typecheck`, `pnpm build` и `pnpm test:integration` проверяют принятые контракты без изменения тестов и исходного кода.

Для полного `pnpm e2e` используется собранный `next start --hostname 127.0.0.1`, отдельный свободный порт и согласованные синтетические env. `E2E_WEBSERVER` отсутствует, поэтому Playwright не запускает dev server. Синтетическая БД назначена отдельно; чужие env и реальные аккаунты не используются. Разрешённая encoded-cookie сессия подтверждает session transport, а успешный ввод пароля покрыт только unit-тестом provider, не password-login E2E.

## Ограничения

Локальные PostgreSQL 16.14 и macOS не воспроизводят CI PostgreSQL 17 и Ubuntu. Remote CI, публикация, deployment и rotation не выполнены. Старый работающий deployment этим локальным commit не обновляется. Пакет не закрывает все advisories, Auth-риски или lint; ограничения B01a.1–3 сохраняются. После будущего применения rollback должен сохранять patched Next и session/containment ограничения; возврат 15.5.20 не является безопасным rollback.
