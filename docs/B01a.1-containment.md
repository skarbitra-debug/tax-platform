# B01a.1 — локальное ограничение legacy web

База: `cf995e8ea81c52a64c6b496334c90df07a617b9d`. Это локальное изменение, не доказательство защищённого demo.

## Закрытые входы

- submitApplication и registerRealtor безусловно отказывают до чтения формы, метаданных, rate limit, БД и авторизации.
- ФНС actions отказывают без проверки роли и вызова сервисов. Сервисы не читают env, БД или ciphertext; set/clear бросают FNS_ACCESS_DISABLED, reveal возвращает DISABLED. Существующие записи не удаляются.
- sendHandoffToChannel возвращает false без чтения ПД/конфигурации, сети и изменения handoffSentAt; resend action возвращает отказ. Прямой вызов со старой страницы не включает путь обратно.
- `/r/[token]` и `/register` показывают остановку приёма без форм. Карточка admin не запрашивает ФНС-данные и не показывает ФНС/повторную отправку.

Нет переключателя env, исключения ADMIN или тестового bypass. Публичные сигнатуры actions/services сохранены; запрещённые старые тела удалены.

## Проверки

```sh
pnpm --filter @tax/web test
pnpm test
pnpm typecheck
pnpm build
E2E_BASE_URL=http://127.0.0.1:3319 pnpm e2e e2e/funnel.spec.ts
git diff --check
```

Подготовка: frozen install с --ignore-scripts и pnpm db:generate с синтетическим локальным DATABASE_URL. Web запускать отдельно по e2e/README.md. Бот не запускать. Browser smoke анонимный, без seed, регистрации и отправки заявок. Services/actions тестируются через реальные exports с изолированными внешними зависимостями и проверкой отсутствия side effects.

pnpm lint baseline является no-op, не доказательством проверки. Полный integration suite не входит в этот пакет: core/Prisma не меняются.

## Открытые риски и rollback floor

B01a.2 отдельно закрывает legacy bot polling/voice/bootstrap. B01a.3 — известные dev identities и отзыв JWT/сессий; дополнительные изменения seed требуют явного scope следующего плана. Обычный login/logout, действующие права на ПД и другие authenticated writers не изменены. H10/U1 целиком не закрыты. Реальные секреты, существующие записи, схема и миграции не менялись; коммерческие решения не принимались.

B01b требует отдельного разрешения владельца и проверки live SHA/окружения. Публичный push и deployment этим пакетом не разрешены.

После будущего live containment нельзя откатывать на baseline или старый image, возвращающий запрещённые пути. Допустимый rollback обязан сохранять ограничения. Локальные ветки и коммиты сохраняются; reset/clean чужих деревьев не используются.
