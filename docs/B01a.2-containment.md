# B01a.2 — локальная остановка legacy bot

Input — принятый локальный B01a.1 `b23c92730a8f1d1c611acda0bbee6762dba225f6`.

## Закрытые границы

`apps/bot/src/index.ts` больше не импортирует env/Prisma/grammY/voice, не создаёт Bot, admin binding, handlers и polling. Он выводит одну строку `Legacy bot disabled.` и естественно заканчивает процесс с exit 0, без таймеров/process.exit.

`handleVoice(ctx)` при прямом вызове отклоняет Promise с `LEGACY_BOT_DISABLED` до чтения ctx: нет Telegram reply, download, STT, DB или domain writer. Type-only Context сохранён. STT API совместим: `createStt()` возвращает inert adapter, `transcribe()` отклоняет Promise с той же ошибкой; `isSttConfigured()` возвращает false. Нет env-переключателя включения, spawn/ffmpeg/transformers/model download.

## Локальные проверки

```sh
pnpm --filter @tax/bot test
pnpm --filter @tax/bot typecheck
pnpm --filter @tax/bot build
```

Только после GREEN tests и просмотра собранного `apps/bot/dist/index.js` допускается `pnpm --filter @tax/bot start` в очищенном процессе без Telegram/DB env. Ожидается быстрый естественный exit 0 и одна фиксированная строка приложения. Старый baseline start не использовать для RED: он начинает внешние действия.

Общий regression: `pnpm test`, `pnpm typecheck`, `pnpm build`, `git diff --check`. Frozen install без lifecycle scripts; Prisma generation для workspace typecheck/build с синтетическим локальным DATABASE_URL. База, seed, миграции и web E2E для этого пакета не нужны: web/core/schema не меняются.

## Что этот результат не означает

Exit 0 означает выключенный компонент, а не здорового работающего бизнес-бота. Изменение локального artifact не останавливает уже запущенный старый процесс. Действующий bot token/webhook/supervisor не менялись; deployment/remote publication не выполнялись. В baseline compose стоит restart unless-stopped: возможный перезапуск выключенного artifact должен отдельно учитывать B01b, не менять supervisor молча в этом пакете.

Core voice/status остаются библиотечными функциями. Другие web writers и права на ПД не закрыты этим пакетом. B01a.3 отдельно закрывает known dev identities и JWT/session invalidation; дополнительный seed hardening не обещается автоматически. H10/U1 полностью не закрыты; live containment не подтверждён.

После будущего live containment старый bot image не является безопасным rollback: восстановление должно сохранять disabled polling/bootstrap/voice/STT. Локальные ветки/коммиты сохраняются, чужие деревья не очищаются.
